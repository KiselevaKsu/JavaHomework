Отношение между классами, при котором поля и методы одного класса (суперкласса) передаются другому классу (подклассу) без необходимости их повторного определения, называется наследованием.

Для указания наследовании используется ключевое слово extends

class Parent {
    void method() {
        System.out.println("Метод суперкласса");
    }
}

class Child extends Parent {
    void method() {
        System.out.println("Метод подкласса");
    }
}

Множественное наследование классов запрещено.

Если метод объявлен со спецификатором final, то его запрещено переопределять в подклассе.
Если класс объявлен со спецификатором final, то для него невозможно создать подкласс.

Ключевое слово super применяется для:

обращения к конструктору суперкласса
доступу к полю суперкласса
доступу к методу суперкласса

Ключевое слово this используется как ссылка на текущий экземпляр класса, с помощью которой можно получить доступ к полю или методу этого экземпляра.

Перегружаемые (overloading) методы - это методы, у которых совпадает название и тип возвращаемого значения, но отличаются параметры.

Переопределенный (overriding) метод - это метод подкласса, у которого в суперклассе есть полные "двойник", т.е. метод с таким же названием и такими же параметрами.

Использование переопределенных методов позволяет выбирать метод для вызова во время выполнения программы, ориентируясь на тип объекта. Это называется динамическим связыванием - концепцией, реализует полиморфизм.

Для идентификации переопределенных метода используется аннотация @Override.

class A {
    public static void method() {
        ...
    }
}

class B extends A {
    @Override
    public static void method() {
        ...
    }
}

Абстрактные классы объявляются с ключевым словом abstract.

Они могут содержат объявления абстрактных методов, которые должны быть реализованы в подклассах.

Экземпляры абстрактных классов нельзя создать напрямую, но можно объявить переменные такого типа.

Абстрактные классы могут содержать полностью реализованные методы, конструкторы и поля данных.

Класс Object - суперкласс всей иерархии классов Java

Основные методы класса Object:

protected Object clone() — создает и возвращает копию вызывающего объекта
public boolean equals(Object ob) — используется для сравнения объектов
public Class<? extends Object> getClass() — возвращает экземпляр типа Class;
public int hashCode() — вычисляет и возвращает хэшкод объекта
public String toString() — возвращает представление объекта в виде строки
Эти и другие методы класса Object могут быть переопределены в любом классе Java.

Каждый класс в Java должен принадлежать определенному пакету, название которого задается оператором package.

Если этот оператор отсутствует, то класс принадлежит неименованному пакеты (default package).

Каждый класс компилируется в соответствующий каталог, задаваемый именем пакета.

Для получения доступа к классу из другого пакета используется ключевое слов import.
