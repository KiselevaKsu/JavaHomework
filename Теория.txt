Исключение (Exception) - это объект некоторого класса, которые возникают в нормальном потоке программы и могут быть "пойманы" и обработаны.

Иерархия основных классов исключений:

java.lang.Object
   └── java.lang.Throwable
        ├── java.lang.Error
        └── java.lang.Exception
             └── java.lang.RuntimeException

При возникновении исключений обработчик сначала ищется в текущем методе и если там он не находится, то исключение передается вверх по стеку вызовов. В случае если исключение не будет перехвачено происходит аварийное завершение приложение.

Обработка исключений происходит один из следующих способов:

с помощью блока try-catch-final
через объявление throws в заголовке метода

Если метод собирается "ловить" несколько типов исключений то блок try-catch может содержать несколько секций catch.

При использовании в catch оператора | для объединения нескольких исключений нельзя допускать, чтобы эти исключения были из одной "иерархической цепочки".

Операторы try можно вкладывать друг в друга.

Генерировать исключительные ситуации можно "вручную" с помощью оператора throw. В качестве исключения должен быть использован объект подкласса класса Throwable.

С помошью оператора new экземпляр подкласса класса Throwable можно создать прямо в throw.

try {
  ...
  Throwable subclassThrowable = new SubclassThrowable();
  throw subclassThrowable;
  ...
  throw new SubclassThrowable();

} catch (final Exception e) {
   ...
}

Для создания собственных исключение, нужно создать класс, унаследованный от класса Exception. По договоренности этот класс должен заканчиваться словом Exception, например класс может называться MyFirstException.

У подклассов класса Exception обычно определяют минимум три конструктора.

В случае если в приложении произошла критическая ошибка, при которой приложение не может нормально продолжать работу обычно генеруруют исключение, являющееся подклассом класса RuntimeException.


Если в приложении нужно выполнить действие вне зависимости от того, произошло исключение или нет, используют блок finally.

try {
  ...
} catch(...) {
  ...
} catch() {
  ...
} finally {
  // Это код выполниться всегда
}
