Внутри класса могут быть определены другие классы.

Эти классы могут быть объявлены как нестатические, т.е. для их использования требуется создать экземляр, и тогда их называют внутренними классами (inner class), а могут быть объявлены как статические, тогда их называют вложенными классами (nested class).

Класс, внутри которого объявляется другой класс, называет внешним.

Объект внутреннего класса скрыто хранит ссылку на объект создавшего его внешнего класса (enclosing object).

public class ClassA {
    private InnerClassA ic;

    public class InnerClassA {
        private String a;
    }

    public class InnerClassB {
        private String b;
    }

    ...
}

ClassA.InnerClassA = new ClassA().new InnerClassA();
ClassA.InnerClassB = new ClassA().new InnerClassB();
Возможность использования внутреннего класса извне определяется его спецификаторами доступа.

Вложенный класс определяется как статический класс "внутри" внешнего класса.

public class ClassA {

    public static class NestedClass {
        public void func() {
          ...
        }
    }
  ...
}

ClassA.NestedClass = new ClassA().NestedClass();
Вложенному классу доступно только статическое содержимое внешнего класса.

Анонимные классы (anonymous inner class) - это вариант внутреннего класса.

Анонимные классы не имеют имени и создаются в момент инициализации объекта на основе существующего класса или интерфейса.

public class Class1 {
  public void print1() {
    ...
  }
}

public interface Interface2 {
  public void print2();
  ...
}

public static void main(String[] args) {
  // Обычный экземпляр класса
  Class1 ex1 = new Class1();
  ex1.print1();

  // Анонимный класс, построенные на классе
  Class1 aex1 = new Class1() {
    // переопределение существующего метода
    @Override
    public void print1() {
      ...
    }
  };
  aex1.print();

  // Анонимный класс, построенные на интерфейсе
  Interface2 iex2 = new Interface2() {
    // определение метода
    @Override
    public void print2() {
      ...
    }
  };
  iex2.print();
}
Свойства анонимных классов:

нельзя определить конструктор для анонимного класса
нельзя создать анонимный класс из final класса
анонимный класс может использовать только неизменяемые параметры и локальные переменные метода, в котором он создан
в анонимном классе можно объявлять собственные поля и методы, которые не доступны объекту вне этого класса
