Начиная с Java версии 8 класс String хранит строку в виде массива элементов типа byte.

Объект класса String являются константами.

Литералы, которые используются для создании экземпляров класса String, помещаются в специальную область - "пул литералов" и становятся объектами-литералами, ссылки на которые могут многократно переиспользоваться.

В отличии от класса String, классы StringBuilder и StringBuffer не являются константными, т.е. их содержимое может динамически изменяться.

StringBuffer является потокобезопасным методом, в отличии от StringBuilder.

Для форматированного текстовых данных используется класс java.util.Formatter.

Для форматировании используются спецификаторы:

Спецификатор формата	Выполняемое форматирование
%b	Логическое значение аргумента
%c	Символьное представление аргумента
%d	Десятичное целое значение аргумента
%h	Хэшкод аргумента
%e	Экспоненциальное представление аргумента
%f	Десятичное значение с плавающей точкой
%n	Вставка символа новой строки
%s	Строковое представление аргумента
%t	Время и дата
%%	Вставка знака %

Для форматирования времени и даты могут использоваться следующие спецификаторы.

Спецификатор формата	Выполняемое преобразование
%tH	Час (00–23)
%tI	Час (1–12)
%tM	Минуты как десятичное целое (00–59)
%tS	Секунды как десятичное целое (00–59)
%tL	Миллисекунды(000–999)
%tY	Год в четырехзначномформате
%ty	Год в двузначном формате (00–99)
%tB	Полное название месяца («январь»)
%tm	Месяц в двузначном формате (1–12)
%tA	Полное название дня недели («пятница»)
