Переменные класса, экземпляра класса и константы
В классе могут присутствовать следующие данные:

поля класса - переменные, объявленные в классе
локальные переменные - переменные, объявленные в методе или блоке кода
параметры метода - переменные, указанные в объявлении метода
Поля класса имеют спецификатор и тип. Тип может быть базовый или объектный.

Спецификатор static объявляет статическое поле класса, доступное на уровне класса, т.е. для всех объектов класса это поле имеет одно и то же значение.

Поле класса, объявленное без спецификатора static - наиболее частый случай - объявляется на уровне объекта, т.е. каждый объект класса будет иметь свое значение данного поля.

Поля класса и методы могут быть объявлены с одним из следующих спецификаторов доступа:

public
protected
private
Поля класса, локальные переменный и параметры метода со спецификатором final не могут быть переприсвоены после инициализации.

Локальные переменные не инициализируются значениями по умолчанию при создании объектов класса и вызове методов.

Настройка доступа к данным и методам обеспечивается четырьмя спецификаторами доступа (видимости):

private - члены класса доступны только членам данного класса
по умолчанию (без спецификатора) - члены класса доступны классам, находящимся в том же пакете
protected - члены класса доступны классам, находящимся в том же пакете и подклассам в других пакетах
public - члены класса всем классам в этом и других пакетах
Спецификатор public для методов и конструкторов обеспечивает внешний доступ к функциональности пакета, в котором он объявлен.

Использование спецификатора private обеспечивает инкапсуляцию.

Действие спецификатора распространяется только на тот элемент класса, перед которым он стоит.

Конструкторы

Конструктор - это особый метод, который вызывается при создании экземпляра класса с помощью оператора new.

Свойства конструктора:

Имя конструктора должно совпадать с именем класса.
Конструктор используется только с оператором new.
Конструктор не возвращает значения (в коде нет return).
Конструктор может иметь параметры.
В классе может быть несколько конструкторов.
Если в классе не определено ни одного конструктора, то компилятор сам добавить конструктор по умолчанию (без параметров).
Если в классе определен хоть один конструктор, то компилятор не добавляет конструктор по умолчанию (без параметров).
Конструктор подкласса может вызвать конструктор суперкласса через super(...). Если вызов указан явно, то он должен быть сделан в первой строке кода конструктора подкласса. Если вызов явно не указан, то компилятор вызовет super() сам.
Конструктор может объявлен со спецификатором доступа.
Конструктор НЕ может быть объявлен как: static, final, abstract, synchronized, native,
В Java отсутствуют деструкторы. Память очищается "сборщиком мусора".

Однако есть depricated-метод finalize(), который вызывается каждый раз, когда "сборщик мусора" уничтожает объект, на который никто не ссылается.

Кроме явно определенных данных в коде класса можно использовать ссылку this, которая указывает "сама на себя", т.е. на созданный экземпляр класса.

МЕТОДЫ
Методы могут объявляться только внутри класса.

Если метод не возвращает значения, то ключевое слово return либо не указывается, либо записывается без аргумента.

void method()
{
    ...
    return;
}
К методам применяются спецификаторы доступа.

Методы можно перегружать (overloading). На перегрузку влияют количество и типы аргументов. Тип возвращаемого значения на перегрузку не влияет.

Методы суперкласса можно переопределять (override) в подклассах.

Статические методы и поля
Спецификатор static показывает, что метод или поле логически "привязаны" к классу, а не к экземпляру класса.

Статическое поле (другое название - переменная класса) - общее для всех объектов и может быть использовано без создания экземпляра класса.

Для работы со статическими полями могут использоваться как статические, так и нестатические методы. Изменение статического поля увидят все объекты.

Из статических методов нельзя получить доступ е нестатическим методая или полям.

Статические методы определяются на этапе компиляции и никаким образом не могут быть заменены другой реализацией.


Модификатор final используется в:

классах
метода
членах класса
локальных переменных
параметрах метода
Для final-классов нельзя создавать подклассы.

Final-методы нельзя замещать в подклассах.

Члены класса, локальные переменные и параметры методов, объявленные как final становятся константами.

Константы не могут получить значение по умолчанию, поэтому должны быть проинициализированы.

Абстрактные методы размещаются в абстрактных классах и интерфейсах и должны быть реализованы в подклассах.

Абстрактный класс может содержать неабстрактные методы.

public abstract class A {
    public void method1() {
        System.out.println("method1");
    };
    public abstract void method2();
}

public class B extends A {
    public void method2() {
        System.out.println("method2");
    };
}
Интерфейс может содержать только абстрактные методы.

public interface I {
    public void method3();
}

public class C implements I {
    public void method3() {
        System.out.println("method3");
    };
}
Невозможно создать экземпляр абстрактного класса или интерфейса.

Логический блок - код, заключенный в фигурные скобки и не принадлежащий ни одному методу.

public class A {
    ...
    {
        // code
    }
    ...
}
Логические блоки могут использоваться для инициализации полей. Они могут содержать вызовы методов и обращение к полям текущего класса (только через this).

При создании объекта они вызываются последовательно в порядке размещения. Конструктор вызывается после выполнения последнего блока.

Если логический блок объявлен как static, то он вызывается единственный раз при создании первого объекта или при первом обращении к статическому полю или методу.

public class A {
    ...
    static {
        // code
    }
    ...
}
Логические блоки не наследуются.
статический блок выполняется первым при загрузке класса.

Перегрузка метода (overloading) - наличие нескольких методов с одним и тем же названием, но разным набором параметров.

Перегрузка может быть выполнена как в рамках одного класса, так и в разных классах, находящихся в одной "цепочке" наследования.

Перегрузка, т.е. определение версии вызываемого метода, осуществляется на этапе компиляции.

Параметризация позволяет создавать классы, интерфейсы и методы, в которых тип обрабатываемых данных задается как параметр.

class Wrapper<T> {
    private T item;

    public void setItem(T item) {
        this.item = item;
    }

    public T getItem() {
        return item;
    }
}

Wrapper<Integer> int1 = new Wrapper<>();
Wrapper<Integer> int2 = new Wrapper<Integer>();
При создании объекта все фиктивные типы будут заменены на реальные.

На generic-типы действует ряд ограничений:

невозможно явно вызвать констуктор:
class Failed1<T> {
  private T t = new T();
}
generic-поля не могут быть статическими
class Failed2<T> {
  static T t;
}
статические методы не могут иметь generic-параметры
class Failed3<T> {
  static void func(T t) {
    ...
  };
}
generic-типы не могут быть примитивными
class Failed3<T> {
  static void func(T t) {
    ...
  };
}

Для ограничение типов, которые используются для параметризации, можно использовать конструкции extends и super.

class Wrapper1<T extends someType> {
    public T item;
    ...
}

class Wrapper2<T super someType> {
    public T item;
    ...
}

Параметризованный метод определяет базовый набор операций, которые будут применяться к разным типам данных, получаемых методом в качестве параметра.

class ClassEx {
    public <T> void method(T item) {
        ...
    }
}

ClassEx x = new ClassEx();
x.<Integer>method(Integer.valueOf(1));
Параметризованный метод может находиться как в параметризованном классе, так и в обычном.

Методы могут быть определены с переменным числом параметров.

Параметры, передаваемый в такой метод, преобразуется в массив.

public static void printNumbers(int... numbers) {
    for (int num : numbers) {
        System.out.println(num);
    }
}

public static void printObjects(Object... objs) {
    for (Object obj : objs) {
        System.out.println(obj.toString());
    }
}
Методы с переменным числом параметров могут быть перегружены.

Перечисления (enum) — тип данных, который позволяет задавать фиксированный набор констант.

public enum Day {
    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY
}

Day day = Day.MONDAY;

switch (day) {
    case MONDAY:
        System.out.println("Начало недели!");
        break;
    case FRIDAY:
        System.out.println("Пятница!");
        break;
}

Перечисления не может

быть суперклассами;
быть подклассами;
быть абстрактными;
быть параметризированными;
создавать экземпляры, используя ключевое слово new.
