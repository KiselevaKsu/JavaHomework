Базовые типы не являются объектами. Их значения (литералы) размещаются в стековой памяти (stack).
Для каждого базового типа имеются классы-оболочки, которые инкапсулируют данные базовых типов в объекты, располагаемые в динамической памяти (heap).
Существует восемь базовых типов данных.
Тип	Название	Количество бит
Целочисленные	byte	8
short	16
int	32
long	64
С плавающей точкой	float	32
double	64
Символьный	char	16
Булевский	bool	
В Java не существует беззнаковых типов.
Классы Character и String обеспечивает поддержку стандарта Unicode.
Переменные, представляющие собой, как объекты, так и базовые типы, могут быть
членами класса
локальными переменными метода
параметрами метода
Переменная базового типа, объявленная как член класса, хранит нулевое значение, соответствующее своему типу.
Переменная базового типа, объявленая как локальная переменная в методе должна быть обязательно проинициализирована перед использованием.
Область действия и время жизни такой переменной ограничена блоком {}, в котором она объявлена.
Строки, заключенные в двойные апострофы, считаются литералами и размещаются в пуле литералов, но в то же время 
такие строки представляют собой объекты класса String - объекты из набора (массива) символов.

В арифметических выражениях автоматически выполняются расширяющие преобразования базового типа:
byte -> short -> int -> long -> float -> double

Любая операция с участием различных типов даст результат, тип которого будет соответствовать большему из типов операндов.
Для сужения диапазона значений необходимо производить явное преобразование вида (type)value.

int i = 100;
byte b = (byte) i;
Type inference (вывод типов) - возможность компилятора автоматически определять тип переменной на основе значения. var позволяет объявить переменную без явного указания типа.
