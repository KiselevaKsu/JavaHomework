Существует четыре типа циклов:

while
do-while
for(;;)
for для массивов и коллекций
while - цикл с предусловием.
int value = 1;
while(value < 10) {
    value++;
}
Могут быть ситуации, когда тело цикла не выполнится ни разу.

do-while - цикл с постусловием.
Такой цикл гарантировано выполнится один раз.

int value = 1;
do {
    value++;
} while(value < 10);
for(;;) - цикл с параметрами.
Количество итераций определяется параметрами цикла.

for (int i = 0; i <= 10; i++) {
    // код
}
Первая и последняя "секции" цикла могут содержать несколько операций.

for (int i = 0, j = 10 ; i <= 10; i++, j--) {
    // код
}
Центральная (вторая) "секция" должна иметь логическое условие, проверка которого обеспечивает выполнение очередной итерации цикла. Если логическое условие указано неверно или отсутствует, то цикл может стать бесконечным.

for (;;) {
    // код, который будет выполняться бесконечно
}
Если цикл делается бесконечным намеренно, то из него должен быть выход. Для этого используются оператор break.

Если какую-то итерацию в цикле требуется "пропустить", то можно использовать оператор continue.
for - цикл для массивов и коллекций.
Позволяет получить доступ ко всем элементам без исползования индексов.

int[] arr = {1, 3, 5, 7, 9};
for (int elem : arr) {
    System.out.printf("%d ", elem);
}
Изменять значение элементов итерируемого объекта с помощью оператора = в таком цикле невозможно.
