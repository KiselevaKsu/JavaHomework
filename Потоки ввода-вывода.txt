InputStream — абстрактный класс для всех байтовых потоков ввода.

OutputStream — абстрактный класс для всех байтовых потоков вывода.

Система вывода в Java использует стандартные потоки для вывода данных и ошибок - System.out и System.err, которые являются ссылками на объекты класса PrintStream.

Для стандартного потока ввода используется System.in.

Эти потоки по умолчанию связаны с консолью. 

Класс java.util.Scanner используется для получения данных из различных источников. Он преобразует ввод в двоичное представление.

Для получения данных из консоли нужно создать объект и использоваться его для получения данных.
Scanner console = new Scanner(System.in);
int number = console.nextInt();
String str = console.next();
