Класс соответствует типу данных. Тип данных - описание совокупности объектов предметной области с общими атрибутами, методами, отношением и семантикой.

Объект - конкретный экземляр класса.

Объектно-ориентированное программирование (ООП) — это методология про- граммированния, основанная на использовании классов и объектов.

В ООП используются принципы:

инкапсуляции
наследования
полиморфизма
Инкапсуляция (encapsulation) — принцип, объединяющий данные и код, который защищает данные от прямого внешнего доступа, т.е. доступ к данным класса осуществляется только с помощью методов этого же класса.

Наследование (inheritance) — процесс, при котором один класс может наследовать поля и методы другого класса, изменять их и добавлять к ним свои поля и методы.

Наследование бывает двух видов:

одиночное наследование
множественное наследование
При одиночном наследовании — подкласс (производный класс) имеет только один суперкласс (предок).

При множественном наследование — подкласс может наследовать любое количество суперклассов. В Java множественное наследование для классов запрещено, но в можно наследовать любое количество интерфейсов.

Полиморфизм (polymorphism) — механизм, использующий одну и ту же сигнатуру метода для решения схожих задач, но в разных подклассах.

В Java реализован механизм "позднего связывания" или "динамического полиморфизма". Это значит, что при вызове метода объекта определяется к какому имеено классу принадлежит объект и используется метод именно этого класса. Такую задачу невозможно решить на этапе компиляции - "статический полиморфизм". Она решается в процессе выполнения программы - "динамический полиморфизм".
