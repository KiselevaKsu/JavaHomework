Комментарии бывают двух типов: блочные и однострочные

/*
Это блочный комментарий
*/
// Это однострочный комментарий
int a = 1; // Это тоже однострочный комментарий
Для документирования класс, метода или поля используется специальный комментарий /** */ в сочетании с дескрипторам.

/**
    Список некоторых дескрипторов
    @author - сведения об авторе
    @version - номер версии
    @param - параметры, передаваемые методу
    @return - тип, возвращаемый методом
    @depricated - помечает метод, как устаревший
    @since - версия, с которой данный элемент присутствует
    @exception - исключения, генерируемые методом
    @throws - исключения, генерируемые методом
    @see - дополнительная информация
*/
